# 常见问题 Q&A

## 标题或设置数据消失了

清理浏览器缓存或网站数据可能会清除本地保存的数据。如果此前导出过备份，可在“其他”选项卡中恢复数据。

## 无法更新标题至 Twitch

请确认 Token 是否有效、是否已勾选 `channel:manage:broadcast` 权限，以及游戏分类名称是否完全正确。点击“同步”可获取官方分类名称。

## Twitch 已更新，但 OBS 原生直播信息 Dock 未改变

请手动重新加载 OBS 原生的直播信息 Dock，或在该 Dock 获得焦点时按下 `Ctrl + R`。

## 可以使用自定义音效文件夹吗？

可以。请通过“选择音频文件夹”进行设置。受浏览器安全机制限制，重启 OBS 或重新加载页面后需要重新选择文件夹。

## 一般浏览器的设置没有反映至 OBS Dock

普通浏览器与 OBS Dock 的本地存储彼此独立。请先从一端导出备份，再在另一端恢复，以同步设置。
