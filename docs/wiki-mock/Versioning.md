# バージョン管理

## 現在のバージョン

- 開発版: 0.9_beta
- 正式版: 1.0.0（2026年7月25日公開予定）

## バージョンの付け方

| 種類 | 例 | 内容 |
| --- | --- | --- |
| 開発版 | 0.9_beta | devで修正を集め、公開前に確認する版 |
| 正式版 | 1.0.0 | mainで公開する最初の正式版 |
| 軽微なバグ修正 | 1.0.1 | 機能を変えない修正版 |
| 機能追加 | 1.1.0 | 後方互換性を保った機能追加版 |

開発版は`X.X_beta`の2桁、mainで公開する正式版は`X.Y.Z`の3桁で管理します。

開発中の修正はdevへプルリクエストを送り、公開内容を確認してからmainへ反映します。0.9_betaで確認した内容を、正式版1.0.0として公開します。
