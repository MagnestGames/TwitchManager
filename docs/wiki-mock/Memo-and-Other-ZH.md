# 备忘录与其他功能

## 备忘录

将开播准备、直播话题与流程保存为多张卡片。

![备忘录界面](images/features/memo-pad.png)

点击 **「＋」** 添加卡片。解除排序锁定后可以拖动排序；打开删除模式即可移除不需要的卡片。

使用范例：
- 开播话题备忘
- 游戏或企划流程
- 合作直播当天的流程
- 下次开播的待办事项

## 备份与恢复

![备份与恢复界面](images/features/backup-restore-logs.png)

- **备份**: 复制设置数据或保存为文字／JSON 文件。
- **恢复**: 加载备份 JSON 文件，并选择覆盖或合并现有设置。

*执行恢复前，请务必先导出当前数据的备份。*

## 活动日志

可查看身份验证、通知、Raid 介绍和命令执行日志。报告问题并附上日志时，请确认其中不含个人 Token 等敏感信息。
