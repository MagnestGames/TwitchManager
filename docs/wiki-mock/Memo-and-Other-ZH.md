# 備忘錄與其他功能

## 備忘錄

將開播準備、實況話題與流程儲存為多張卡片。

![備忘錄介面](https://raw.githubusercontent.com/MagnestGames/TwitchManager/dev_0.9_beta/docs/wiki-mock/images/features/memo-pad.png)

點擊 **「＋」** 新增卡片，解鎖狀態下可進行拖曳排序。開啟刪除模式即可移除不需要的卡片。

使用範例：
- 開播話題備忘
- 遊戲或企劃流程
- 聯動實況當日流程
- 下次開播的待辦事項

## 備份與還原

![備份與還原介面](https://raw.githubusercontent.com/MagnestGames/TwitchManager/dev_0.9_beta/docs/wiki-mock/images/features/backup-restore-logs.png)

- **備份**: 複製設定資料或儲存為文字／JSON 檔案。
- **還原**: 載入備份 JSON 檔案，選擇覆蓋或合併現有設定。

*執行還原前，請務必先匯出當前資料的備份。*

## 活動日誌

檢視身份驗證、通知、Raid 介紹與指令執行的運作日誌。回報問題回傳日誌時，請確認未包含個人 Token 等敏感資訊。
