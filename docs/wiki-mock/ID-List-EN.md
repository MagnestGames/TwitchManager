# ID List Management

Organize information about fellow streamers, collab partners, and raid candidates into manageable cards.

![ID List Management](images/features/id-list-management.png)

## Stored Information

- Display Name & Twitch Login ID
- Social links (X/Twitter, YouTube)
- Notes & Memos
- Birthdays & Anniversaries
- Tags & Group categories
- Shoutout count & Last shoutout date

Click **"+ Add"** to create cards or new groups. A single streamer can be assigned to multiple groups, and you can filter the list using top tag pills.

Sort options include: Name, Group, Last Shoutout Date, Shoutout Count, and Birthday. Make sure to enter their official Twitch login username (ID), not just display names.

## Birthdays & Anniversaries

Registered dates will trigger top notification alerts and populate the anniversary calendar.

![Birthday Notification](images/features/id-list-birthday-popover.png)

![Anniversary Calendar](images/features/id-list-calendar.png)

*Remember to periodically create a [Data Backup](Settings-and-Backup-EN) of your ID List.*
