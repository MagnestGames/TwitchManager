# 直播标题与分类管理

将直播标题与游戏分类保存为卡片，方便一键同步更新至 Twitch。

![标题管理界面](images/features/title-management.png)

## 创建预设卡片

1. 点击 **「＋ 添加模板」**，为特定游戏或企划创建分组。
2. 点击模板右上角的 **「＋」** 按钮添加卡片。
3. 输入游戏分类与直播标题后保存。

*注意：卡片中的通知正文、标签和备忘录仅供个人开播准备时参考。只有“标题”和“分类”会直接更新到 Twitch。*

## 同步与更新

- **「同步」**: 读取 Twitch 当前的直播标题与分类。
- **「更新」**: 将所选卡片内容提交并应用到 Twitch。

游戏分类名称必须与 Twitch 官方名称一致。建议先在 Twitch 中设置一次，再点击“同步”，以避免输入错误。

若 OBS 原生的直播信息 Dock 未实时更新，请重新加载该 Dock 或按下 `Ctrl + R`。

可点击铅笔图标修改卡片名称。建议在开播前完成卡片的排序与删除，以防误触。
