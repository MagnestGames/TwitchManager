# TwitchManager Wiki 日本語下書き

GitHub Wikiへ移すための日本語ページとスクリーンショットです。

- Home.mdと_Sidebar.mdから全ページへ移動できます。
- 主要機能はスクリーンショット付きです。
- 画像内のユーザー名と入力値は説明用です。
- 旧ページ名は案内ページとして残しています。

## ローカル確認

preview.htmlをローカルWebサーバーで開きます。

## Wikiへ反映する

1. README.mdとpreview.htmlを除くMarkdownをWikiリポジトリへコピーします。
2. images/をコピーします。
3. ページ内リンクと画像を確認します。
