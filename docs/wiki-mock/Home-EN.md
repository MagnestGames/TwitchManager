# TwitchManager

TwitchManager is a local tool designed to handle stream preparation, live controls, and information management directly from an OBS Custom Dock.

## Features

- **Pre-stream**: Stream title & category setup, ID list management, memo notes.
- **In-stream**: Raid shoutouts, outgoing raid shortcuts, notification sounds, predictions & polls, chat controls.
- **Post-stream**: Supporter & Channel Point reward summary, activity log export, data backup.
