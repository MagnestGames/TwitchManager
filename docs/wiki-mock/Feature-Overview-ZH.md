# 功能总览

| 选项卡 | 功能说明 |
| --- | --- |
| 标题 | 保存、同步和更新直播标题与游戏分类预设 |
| 通知与 Raid | Raid 介绍、发送 Raid 捷径、介绍文模板、自定义音效通知 |
| Twitch | 支持者与频道积分兑换统计、预测与投票、聊天室控制、剪辑、VIP |
| 指令 | 直播、聊天室与用户管理快捷操作 |
| ID 列表 | 主播 ID、社交平台链接、标签、生日与纪念日 |
| 备忘录 | 保存直播笔记与待办事项 |
| 其他 | 备份、恢复与 EventSub 活动日志 |

## 直播工作流程建议

- **开播前**: 设置标题与分类、确认 ID 列表、记录备忘录
- **开播中**: Raid 介绍、发送 Raid、Twitch 工具、命令操作
- **开播后**: 查看支持者统计、频道积分兑换与活动日志、数据备份

同步 Twitch 与接收事件通知需要先完成 [Twitch 身份验证](Authentication-ZH)。您可以在 [设置](Settings-and-Backup-ZH) 中微调要显示的选项卡。
