# 功能總覽

| 分頁 | 功能說明 |
| --- | --- |
| 實況標題 | 儲存、同步與更新實況標題與遊戲分類預設 |
| 通知與 Raid | Raid 介紹、發送 Raid 捷徑、介紹文模板、自訂音效通知 |
| Twitch | 支持者與頻道點數兌換統計、預測與投票、聊天室控制、剪輯、VIP |
| 指令設定 | 實況、聊天室與使用者管理捷徑 |
| ID 列表 | 實況主 ID、社群連結、標籤、生日與紀念日 |
| 備忘錄 | 儲存實況筆記與待辦事項 |
| 其他 | 備份、還原與 EventSub 活動日誌 |

## 實況工作流程建議

- **開播前**: 設定標題與分類、確認 ID 列表、紀錄備忘錄
- **開播中**: Raid 介紹、發送 Raid、Twitch 工具、指令操作
- **開播後**: 查看支持者統計、點數兌換與活動日誌、資料備份

同步 Twitch 與接收事件通知需要先完成 [Twitch 身份驗證](Authentication-ZH)。您可以在 [設定](Settings-and-Backup-ZH) 中微調要顯示的分頁。
