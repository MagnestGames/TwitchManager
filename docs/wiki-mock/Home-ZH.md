# TwitchManager

TwitchManager 是一款本地工具，可直接在 OBS 自定义 Dock 中集成直播准备、直播操作与信息管理。

## 主要功能

- **开播前**: 直播标题与分类设置、ID 列表、备忘录
- **开播中**: Raid 介绍、发送 Raid、通知音效、预测与投票、聊天室操作
- **开播后**: 支持者与频道积分兑换统计、日志导出、数据备份
