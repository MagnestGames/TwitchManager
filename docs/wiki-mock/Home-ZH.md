# TwitchManager

TwitchManager 是一款本地端工具，可直接在 OBS 自訂 Dock 中整合實況準備、實況中操作與資訊管理。

## 主要功能

- **開播前**: 實況標題與分類設定、ID 列表、備忘錄
- **開播中**: Raid 介紹、發送 Raid、通知音效、預測與投票、聊天室操作
- **開播後**: 支持者與頻道點數兌換統計、日誌匯出、資料備份
