# Chat & Management Commands

Frequently used Twitch commands categorized for fast access during your stream.

- **Buttons marked with ✦**: Execute commands directly via the Twitch API.
- **Other buttons**: Copy command templates to your clipboard so you can paste and fill in arguments in chat.

Direct execution requires [Twitch Authentication](Authentication-EN) and appropriate API scopes.

## Stream Management

![Stream Management Commands](images/features/commands-stream.png)

Manage stream title, category, stream markers, raids, and commercial breaks. If you want to automatically send a raid shoutout URL to chat upon raiding, use the `/raid` button under [Notifications & Raids](Raid-and-Notifications-EN).

## Chat Settings

![Chat Settings Commands](images/features/commands-chat.png)

Control chat announcements, chat clear, chat modes, followers-only mode, and slow mode.

## User Management

![User Management Commands](images/features/commands-users.png)

Quick buttons for Ban, Timeout, Mod, VIP, Monitor, Restrict, Block, and Whisper.

## Interactions

![Interaction Commands](images/features/commands-interaction.png)

Trigger polls, predictions, pinned chat messages, and shoutouts. For detailed prediction/poll controls, use [Twitch Tools](Twitch-Tools-EN). For shoutouts, use [Notifications & Raids](Raid-and-Notifications-EN).

> Always double-check target user IDs before executing destructive commands such as Ban, Raid, Commercials, or Role updates. Launching raids requires `channel:manage:raids` scope.
