# IDリスト

コラボ相手やレイド先候補、配信者仲間の情報をカードやカテゴリグループで一括管理します。

![IDリスト](images/features/id-list-management.png)

## 登録・管理できる情報

- **基本情報**: 表示名（ニックネーム）、Twitch ID（英数ID）
- **SNS・リンク**: X（旧Twitter）、YouTubeチャンネル
- **記念日**: 誕生日、活動記念日
- **グループ・整理**: タグ・カテゴリグループ分類
- **配信履歴**: レイド紹介回数および最終紹介日時

「＋ 追加」ボタンで新しいカードやカテゴリグループを作成できます。同じ配信者を複数のグループへ登録でき、グループタグで素早く絞り込めます。

並び順は「表示名」「グループ」「直近の紹介日時」「紹介回数」「誕生日」から自由に切り替えられます。

## 2セグメント方式のコピー機能＆共通タグ連携

IDリストの各カテゴリボタンには、便利な2セグメント形式の操作が用意されています。

1. **タグ文字コピー (`{カテゴリ名}`)**:
   - ボタンの左側（タグ名）をクリックすると、`{グループ名}` という置換タグ文字列がクリップボードにコピーされます。タイトルに入力しておくと、配信送信時に全員の `@ID` に自動置換されます。
2. **ダイレクト `@ID` リストコピー (`@user1 @user2`)**:
   - ボタンの右側（コピーアイコン）をクリックすると、カテゴリ内の全員のTwitch IDが `@user1 @user2` 形式で直接クリップボードにコピーされ、チャットやSNSへすぐに貼り付けられます。

### ツールチップ・事前確認

カテゴリボタンにマウスカーソルを合わせる（ホバーする）と、そのグループに所属する参加メンバー一覧がトースト/ツールチップで表示され、事前のメンバー確認が可能です。

## 重複ID整理モーダル（Duplicate ID Consolidation）

登録件数が増えた際、同じTwitch IDや表記揺れによる重複登録をワンタップで検索・集約できる「重複ID整理」ボタンを搭載しています。

- **衝突解決モーダル**: 重複しているアカウントを検出し、紹介回数やメモ情報を保持したまま1つのカードへ安全に統合します。
- **大小文字の自動不感度判定（Case-Insensitive）**: Twitch IDの `UserA` と `usera` を同一アカウントとして安全に識別・保護します。
