# Feature Overview

| Tab | Key Capabilities |
| --- | --- |
| Title | Save, sync, and apply stream title & game category presets |
| Raid & Notifications | Raid shoutouts, outgoing raid shortcuts, shoutout templates, custom sound alerts |
| Twitch | Supporter & Channel Point reward summary, predictions & polls, chat controls, clips, VIPs |
| Commands | Stream, chat, and user management shortcuts |
| ID List | Streamer IDs, social links, tags, birthdays & anniversaries |
| Memo | Save persistent stream notes and to-dos |
| Others | Backup, restore, and EventSub activity log |

## Recommended Workflow

- **Pre-stream**: Title & category setup, ID list check, Memo notes
- **In-stream**: Raid shoutouts, Outgoing raid shortcuts, Twitch tools, Commands
- **Post-stream**: Supporter summary, Channel Point redemptions & event logs, Data backup

Twitch integration and event detection require [Twitch Authentication](Authentication-EN). You can customize visible tabs via [Settings](Settings-and-Backup-EN).
