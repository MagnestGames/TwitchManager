# 【OBS専用】TwitchManager - 配信管理・支援ブラウザドック

OBS Studioのカスタムブラウザドックに組み込んで、Twitch配信の管理や操作をOBS内だけで完結できる多機能ツールです。

> **🤝 共同開発＆メジャーアップデートのお知らせ**
> 本ツールは、BOOTHで公開されている「[【OBS】ver2！Twitch 配信のタイトルとゲームカテゴリを記録しておけるブラウザドックツール](https://toumei2suisai.booth.pm/items/8164152)」（ショップ：透明に水彩）のアップデート版です。
> 元の開発者「透明に水彩」様と共同開発し、レイド自動紹介やサポーター記録などの強力な新機能を追加し、インストーラーに対応させました。

---

## ✨ 主な機能

1. **配信情報のワンクリック反映**
   よく使うタイトルやカテゴリを保存し、配信前にクリックするだけで反映。
2. **レイド時の自動紹介 ＆ ID記録**
   レイド受信時に自動でチャット紹介や `/shoutout` を実行。相手のIDもリストに自動記録。
3. **見逃し防止の「通知音」**
   チャット、初チャット（初見）、レイド受信時に個別のサウンドで通知。
4. **サポーター・視聴者の行動ログ記録**
   新規フォロー、Bits、サブスク、チャンネルポイント引き換えなどを時系列でログ化。
5. **配信コントロール**
   予測・投票の作成、チャットモード切り替え、クリップ作成などをドックから一発操作。

## 💻 動作環境 ＆ 同梱内容

- **動作環境**: Windows 11 / macOS 11 以降 ＋ OBS Studio
- **同梱内容**: Windows用インストーラー (`.exe`) / macOS用インストーラー (`.pkg`) / 導入マニュアル

---

## 🛠️ かんたん導入手順

1. **インストール**：インストーラーを実行。完了時にOBS登録用のURLが自動コピーされます。
2. **OBSに追加**：OBSの `ドック` ＞ `カスタムブラウザドック` を開き、URLを貼り付けて適用。
3. **連携**：ドック右上の設定（歯車）からTwitchアカウントと連携。
