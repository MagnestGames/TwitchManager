# Issue Draft: 狭小幅・縦型OBSドック表示時のUI崩れ改善とヘッダーメニュー整理

## 目的
縦型ディスプレイやOBSの狭小ドック配置など、ウィンドウ幅を極端に縮小した環境において、UI崩れやボタンの見切れが発生する問題を改善する。
また、使用頻度の低い「色モード切替」「言語切替」を設定モーダル内へ集約し、上部ヘッダーの省スペース化を図る。

## 背景・会話ログ要約
- **発端**: 縦型ディスプレイ利用者より、OBSドック幅を極端に狭くした際の表示崩れ（ヘッダーボタン、タイトルタブ、カード内のSYNC/PUSHボタン・ページャー数字など）の指摘。
- **方針合意**:
  - 色モード切替（ダーク/ライト）と言語切替（JP/EN）は使用頻度が低いため、ヘッダーから「設定（歯車）」内へ移動。
  - 縮小時（極小幅）のカード内要素・ボタン群のレスポンシブ整形（アイコン化・折り返し等）。

## 対象範囲
1. **ヘッダーボタンの整理**:
   - ヘッダーから「ダーク/ライトモード切替ボタン」「言語切替ボタン」を削除。
   - 設定モーダル内に「外観テーマ設定（ダーク/ライト/システム）」および「表示言語設定」を集約。
2. **狭小幅レスポンシブ対応（Media Query / Flexbox最適化）**:
   - **タイトル/通知/ツール タブ**: 狭幅時の自動フォント縮小・パディング調整・折り返し。
   - **タイトルプリセットカード**:
     - ページャー数字（`< 1 >`）と「SYNC取得」「PUSH反映」ボタンの狭幅レイアウト（縦積みまたはアイコン表示への切り替え）。
   - **下部アクションバー**: 「削除」「+ 追加」「保存」ボタンの狭幅時の縮小・アイコン化。

## 対象外
- 各機能（Twitch API連携、データ同期、バックアップ等）の内部ロジック変更
- 既存のPCフルサイズ（標準幅）時の基本レイアウトの改変
